# VL53L1X ToF 测距传感器

## 定位

采用 940 nm Class 1 VCSEL 的单区 ToF 测距器件，官方条件下量程可到约 4 m、最高约 50 Hz，并支持可编程 ROI 缩小视场。适合距离、料位、靠近检测和简单避障。

## 接口与多传感器

- I²C 默认地址 `0x29`；多个 VL53L1X 共用总线时，需要分别控制 XSHUT，上电后逐个修改地址。
- 裸器件供电与 I/O 条件不能按常见 5 V 模块推断；必须绑定具体载板原理图。
- 固件应使用官方 API/ULD 对应版本，并检查测距状态码，而不是只读取距离数值。

## 光学约束

- 最大距离取决于目标反射率、环境光、测量时序预算、ROI 和盖板。
- 透明盖板会产生串扰；必须按最终材料、厚度、间隙和开孔执行串扰/偏移校准。
- 污渍、水滴、强阳光、斜面、细小目标和多路径反射都会降低可靠性。

## 能力边界

单区 ToF 不是二维深度相机。用于安全避障或人员防夹时，需增加覆盖冗余、故障检测和独立安全策略。

## 验证方法

覆盖黑/白目标、不同距离、角度、强环境光、盖板、污渍和温度；记录距离、状态码、信号率、环境光和校准数据；验证 XSHUT 多器件启动流程。
