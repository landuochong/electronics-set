# BH1750 环境光传感器

## 定位

数字环境光传感器，光谱响应接近人眼，常用于显示亮度调节、室内照明检测和简单光照趋势监测。

## 接口与地址

- I²C 地址由 ADDR 引脚选择，常用 `0x23`，另一配置为 `0x5C`。
- 裸芯片供电约 2.4–3.6 V；常见商品模块标称 5 V 时，必须确认是否真正包含稳压或电平转换。
- 支持不同分辨率与连续/单次测量模式；采样周期应等待转换完成。

## 光学安装约束

- 传感器视窗不能被不透明丝印、胶水、灰尘或结构筋遮挡。
- 透明盖板的透过率、颜色、厚度和入射角会改变读数，需要整机标定补偿系数。
- 避免被设备自身 LED、屏幕和状态灯直接照射；室外阳光应用需检查饱和与动态范围。

## 能力边界

BH1750 适合近似照度和趋势判断，不等于经过余弦修正、光谱修正的专业照度计，也不能用于精确 PAR/植物光合有效辐射测量。

## 验证方法

在暗处、室内多档照明和强光条件下与参考照度计对比；验证盖板前后比例、方向性、LED 串扰、地址切换和上电恢复。
