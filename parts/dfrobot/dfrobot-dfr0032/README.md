# DFRobot DFR0032 数字蜂鸣器模块

## 用途

使用数字 GPIO 控制提示音，适合缺水提醒、状态确认和简单报警。

## 接口与供电

- 控制接口：数字 GPIO
- 标称供电：5 V，知识库允许 3.3 V 控制方案进入原型评审。
- 上电默认状态必须为关闭，避免启动阶段误鸣叫。

## 设计约束

- MCU 引脚驱动能力不足或模块输入电平不明确时，应增加三极管/MOSFET 驱动并复核共地。
- 如果产品需要不同音调、旋律或音量控制，应改选无源蜂鸣器和 PWM 驱动方案。
- 用户只说“提示音”时默认使用简单有源蜂鸣器，不额外追问音调。

## 验证建议

验证上电不误响、触发阈值后能够鸣叫、恢复湿润后停止，并记录工作电流和声响可辨识距离。
