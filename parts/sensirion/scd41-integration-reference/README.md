# SCD41 CO₂/温湿度传感器

## 定位

基于光声 NDIR 原理的紧凑 CO₂ 传感器，并提供温湿度数据。适合室内空气质量、通风控制和建筑环境监测；SCD41 的规定精度范围覆盖 400–5000 ppm，并支持单次测量模式。

## 接口与电源

- I²C 固定地址 `0x62`；同总线多器件需要多路复用器或独立电源/总线管理。
- 供电范围 2.4–5.5 V，但逻辑电平和具体载板上拉必须单独确认。
- 测量时存在明显峰值电流，电源和去耦必须按峰值设计，不能按休眠或平均电流选型。

## 安装与气流

- 需要让环境空气自然交换，同时避免风扇直吹、呼吸近距离喷气、灰尘、冷凝和外壳死腔。
- 远离 MCU、稳压器、无线功放等热源；温湿度值容易受到整机自热影响。
- 外壳、泡棉和胶粘剂可能释放气体或限制扩散，应在最终结构中验证响应时间。

## 补偿与校准

- 根据使用场景配置海拔/环境压力补偿和温度偏移。
- 自动自校准要求设备周期性接触接近室外背景浓度；长期密闭或持续有人环境不一定满足前提。
- 强制校准只能在稳定、已知浓度环境下执行，并保存校准条件与时间。

## 验证方法

与可信 CO₂ 参考仪做稳定环境和阶跃响应对比；验证预热、峰值电流、海拔补偿、单次/周期模式、断电恢复和校准策略。不要用人体呼气作为精度标定源。
