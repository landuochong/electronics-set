# Blue Robotics Ping360 扫描成像声呐

## 定位

机械旋转式 750 kHz 扫描成像声呐，可生成平面极坐标声呐图像，用于水下能见度差时的环境观察、结构检查和慢速避障。官方资料给出的量程约 0.75–50 m、最大扫描范围 360°。

## 电气与通信

- 供电 11–18 V，官方明确说明没有反接保护；系统必须增加极性、防浪涌、保险和电源时序设计。
- 支持 USB、Ethernet/UDP、RS485 等集成路径，协议参数包括角度、增益、发射时长、采样周期和样本数。
- 机械扫描速度与量程、角度步进和接口有关，不适合当作高速瞬时全景传感器。

## 声学边界

声呐图像不是光学照片；亮度表示回波强度。气泡、推进器、舱体反射、斜面、软质目标、多径和其他声呐会产生伪影。安装需要无遮挡声学视场并尽量避开气泡流。

## 已知风险

Blue Robotics 在 2024 年技术公告中确认部分 Ping360 在额定范围内的较大深度可能停止工作或图像拖影，仍在调查。用于深水任务前必须核对硬件批次、固件和最新公告，并做目标深度压力测试。

## 验证方法

执行水池标靶、不同距离/角度、推进器开关、多声呐干扰和目标深度压力测试；保存原始声呐帧和所有增益/时序参数，避免只保存渲染截图。
