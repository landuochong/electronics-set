# Blue Robotics SOS 漏水传感器

## 定位

用于水密电子舱的多探头漏水告警模块。正常输出低电平，探头接触水后输出被拉高并点亮指示灯，适合接入 Arduino、Raspberry Pi、Pixhawk 或其他飞控/主控。

## 安装策略

- 探头应放在穿舱件、端盖、最低点和可能积水的位置；单个探头无法覆盖整个舱体。
- 海水、淡水和冷凝水导电性不同；必须按实际介质验证触发时间。
- 探头和海绵需要定期检查、更换并保持清洁，避免盐结晶、腐蚀和污染造成常态误报。

## 电气边界

工作电压 3.3–5 V，最大电流约 20 mA。输出高电平接近 VCC；若以 5 V 供电，连接 3.3 V MCU 前必须确认输入容限或增加电平转换。

## 安全逻辑

漏水传感器是最后一道告警，不替代正确的 O 形圈、穿舱件和压力测试。控制软件应把断线、卡高、卡低纳入诊断，并定义停止推进、上浮、关闭非必要电源和告警通信策略。
