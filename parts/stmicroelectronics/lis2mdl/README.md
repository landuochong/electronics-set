# LIS2MDL 三轴磁力计

## 定位

低功耗三轴数字磁场传感器，量程 ±50 gauss，可用于无人机、机器人和水下机器人的电子罗盘与磁场检测。

## 航向边界

- 磁力计只测磁场矢量；要得到航向必须结合加速度计/IMU 做倾斜补偿。
- 电机、磁铁、钢制紧固件、大电流线束、扬声器和电池会产生硬铁/软铁干扰。
- 水下机器人钢结构、推进器和长电源线通常使磁航向更难可靠，不能把未校准读数直接送入控制器。

## 接口与安装

- 支持 I²C/SPI，I²C 地址 `0x1E`。
- 供电 1.71–3.6 V；独立 I/O 条件和模块上拉需按具体载板复核。
- 尽量远离推进器、电调、DC/DC 和大电流回路；定义芯片、PCB 与机体坐标系变换。

## 校准与验证

执行三维多姿态采样，拟合硬铁偏置和软铁椭球矩阵；分别在电机关闭、不同油门、电池电流和设备装配状态下测试。校准参数应绑定机体和安装位置，而不是绑定单颗传感器型号。
