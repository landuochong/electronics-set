# INA219 电流、电压与功率监测器件

## 定位

12 位高侧双向分流电流与功率监测器，可测量分流电阻压降和 0–26 V 总线电压，并通过 I²C/SMBus 输出电流、电压和功率。适合电源轨、充电/放电和负载功耗监测。

## 接口与供电

- 芯片自身供电 3.0–5.5 V；被测总线可到 26 V。这两个电压概念不能混淆。
- 通过地址引脚组合最多支持 16 个地址，常见模块默认 `0x40`。
- I²C 上拉电压必须与主控逻辑兼容；部分商品模块把上拉接到 5 V，连接 3.3 V MCU 前必须检查。

## 分流电阻决定量程

- INA219 不内置功率分流电阻；模块的最大电流由外部分流阻值、功率、PCB 铜箔、接插件和散热共同决定。
- 驱动中的校准寄存器必须根据实际分流阻值和目标电流量程计算，不能盲用示例库默认值。
- 分流电阻误差、温漂和走线压降会直接进入电流误差；高精度设计应采用 Kelvin 取样。

## 测量边界

- 26 V 是芯片总线电压能力，不代表未知模块的接插件、分流电阻和 PCB 安全满足 26 V/大电流。
- 快速脉冲负载可能被转换时间和数字滤波平均掉；电机、无线发射峰值等需结合示波器或更高速方案。
- 功率寄存器依赖正确校准，读取到数值不代表单位和量程正确。

## 验证方法

使用精密电源、电子负载和参考万用表覆盖零点、正反向、小电流、满量程与温升；核对实际分流阻值和校准系数；验证总线掉电、溢出、地址配置及 I²C 上拉电压。
