# Bitcraze Flow deck v2 光流定高模块

## 定位

由 PMW3901 光流传感器与 VL53L1X ToF 测距器组成的无人机近地定位模块。PMW3901 输出地面纹理的 X/Y 像素位移，VL53L1X 提供离地高度，组合后可辅助悬停和低空速度估计。

## 能力边界

- 光流输出是图像位移，不是直接的米/秒；必须结合离地高度、镜头参数、姿态和时间戳换算。
- 需要可见纹理和足够照明；亮面、透明、重复纹理、纯色地面、强阳光和运动模糊会降低质量。
- 官方标称 ToF 量程可到 4 m，但实际稳定悬停高度还受地面反射率、环境光和飞行姿态限制。

## 集成约束

- PMW3901 走 SPI，VL53L1X 走 I²C；模块是 Crazyflie 扩展板，不是通用即插即用的 Pixhawk 模块。
- 安装方向、旋转矩阵、镜头朝向和传感器相对飞控位置必须写入配置。
- 需要与 IMU 做紧密时间同步；振动和机体滚转/俯仰会把旋转运动投影为光流。

## 水下适用性

普通 PMW3901 光流方案不适合作为通用水下导航传感器。浑浊度、照明、悬浮物、折射窗口和底部纹理都会影响结果；水下速度/位置优先考虑 DVL、声呐和惯导融合。

## 验证方法

覆盖不同高度、速度、光照和地面材质；记录光流质量、像素位移、ToF 距离、IMU 姿态及时间戳；执行失纹理、强光、越界高度和传感器掉线的降级测试。
