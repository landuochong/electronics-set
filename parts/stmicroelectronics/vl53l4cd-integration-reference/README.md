# VL53L4CD ToF 接近传感器

## 定位

面向短距离、高精度和低功耗接近检测的单区 ToF 器件，官方范围约 1–1200 mm、18° 对角视场、最高约 100 Hz，并提供最低约 55 µA 的专用超低功耗检测模式。

## 与 VL53L1X 的选择

- VL53L4CD 更偏向近距离、高线性、窄视场和低功耗唤醒。
- VL53L1X 更偏向较长距离测量。不要只因封装或默认地址相近就直接替换，驱动、调校和使用范围需要重新验证。

## 接口与集成

- I²C 默认地址 `0x29`；多器件同总线需要 XSHUT 顺序启动与动态改址。
- 超低功耗模式依赖专用 API 和阈值配置，不等于普通连续测距模式的功耗。
- 2.8 V 单电源裸器件与常见载板的 3.3/5 V 兼容性必须分开记录。

## 光学与结构约束

最终盖板必须计算排除区并做串扰校准；验证水滴、污渍、阳光、目标反射率、边缘目标和安装偏角。液位检测是特定结构和液体条件下的应用方案，不是任意容器都能直接使用。

## 验证方法

覆盖 1 mm 近端、目标阈值附近和最大应用距离；记录状态码、环境光、信号率与中断；验证 ULP 唤醒误报/漏报、盖板串扰和多器件启动。
