# Blue Robotics Ping 单波束声呐

## 定位

115 kHz 单波束回声测深仪，可用于 ROV/AUV 离底高度、测深、前向大目标距离和简单避障。官方典型量程约 100 m、波束宽度约 25°、耐压等级 300 m。

## 能力边界

- 返回最强回波距离和完整回波曲线，但单波束不能生成二维图像，也不能确定目标在波束内的横向位置。
- 软底、斜坡、气泡、推进器空化、水面反射和其他声呐会产生多径或干扰。
- 100 m 是典型可用范围，不保证所有水体、目标和安装姿态下达到。

## 集成约束

- 可通过串口/RS485 及适配器接入，软件使用 Ping Protocol；保存设备与协议版本。
- 安装时保证换能器声学视场无遮挡，远离推进器气泡流和强机械噪声。
- 多声学设备需要安排频率、触发或时间窗口，避免互相干扰。

## 验证方法

在水池和开放水域覆盖已知距离、软硬底、斜面、不同姿态和推进器工况；同时记录距离、置信度/回波强度和原始 profile；验证无回波、假回波和通信超时的降级逻辑。
