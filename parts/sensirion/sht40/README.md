# SHT40 温湿度传感器

## 定位

小型、低功耗、出厂校准的数字温湿度传感器，适合室内环境、智能家居、便携设备和电池传感器节点。典型湿度精度约 ±1.8 %RH、典型温度精度约 ±0.2 °C。

## 接口与供电

- I²C 固定地址 `0x44`；同一总线上不能直接放置两个 SHT40，除非使用 I²C 多路复用器或独立总线。
- 芯片供电范围 1.08–3.6 V。成品模块可能带稳压器和电平转换，必须以具体载板原理图为准。
- 读取前应执行 CRC 校验；不能只判断总线返回成功。

## 安装约束

- 远离 MCU、稳压器、无线功放、显示背光和充电芯片等热源，避免 PCB 传热造成温度偏高、湿度偏低。
- 传感器开口需要接触被测空气，同时避免冷凝、液态水、助焊剂、清洗剂和挥发性有机物污染。
- 外壳需要通风路径；防水透气膜会增加响应时间，整机响应需实测。

## 加热器边界

片上加热器主要用于冷凝恢复、除湿或污染恢复，不应在加热期间把温度读数当作环境温度。加热周期和占空比必须遵循官方限制。

## 验证方法

- 与可溯源温湿度计做多点对比，至少覆盖低、中、高湿区间。
- 记录外壳封闭前后响应时间与自热偏差。
- 完成上电、CRC 错误、总线恢复、冷凝恢复和长期漂移测试。
