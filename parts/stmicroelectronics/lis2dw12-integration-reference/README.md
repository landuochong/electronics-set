# LIS2DW12 三轴加速度传感器

## 定位

超低功耗三轴加速度计，适合唤醒检测、敲击/双击、跌落、姿态方向、活动识别和电池无线节点。支持 ±2/4/8/16 g、1.6–1600 Hz ODR、32 级 FIFO 与片上运动检测。

## 接口与供电

- 支持 I²C/SPI；I²C 地址可由 SA0 选择，常见为 `0x18`/`0x19`。
- 供电 1.62–3.6 V，并具有独立 I/O 供电设计要求；未知商品模块的稳压和上拉必须复核。
- 低于 1 µA 的工作点依赖特定低功耗模式与配置，不能当作所有 ODR/带宽下的整板功耗。

## 配置边界

- 高性能、低功耗和不同带宽模式的噪声、分辨率与电流不同。
- 自由落体、唤醒、敲击和方向检测的阈值依赖量程、ODR、持续时间和产品安装方向。
- FIFO 与中断用于降低主控唤醒频率，但必须处理水位、溢出和时间对齐。

## 机械约束

定义传感器/PCB/产品三套坐标系；避免板弯、螺丝和冲击应力集中；通过外壳后的振动与共振需要整机验证。

## 验证方法

读取 WHO_AM_I、执行自检和六面静态检查；对唤醒、敲击、跌落、方向与 FIFO 做可重复测试；记录量程、ODR、滤波、阈值和轴变换。
