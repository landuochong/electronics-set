# ICM-42688-P 六轴 IMU

## 定位

集成三轴陀螺仪和三轴加速度计的高性能 IMU，适合机器人、姿态跟踪、穿戴设备、控制器和运动分析。支持 FIFO、中断、外部时钟和片上 APEX 运动功能。

## 接口与地址

- 支持 SPI、I²C 和 I3C；高采样率或强实时性应用优先评估 SPI。
- I²C 地址通常由 AD0 状态选择 `0x68`/`0x69`。
- VDD 与 VDDIO 需要按完整数据手册分别设计；商品载板是否带电平转换必须查原理图。

## 量程与采样

- 加速度量程可选 ±2/4/8/16 g；陀螺仪可选多档量程直到 ±2000 dps。
- 量程、ODR、数字滤波和 FIFO 水位必须依据最大运动、噪声与延迟要求联合选择。
- FIFO 20 位格式、普通寄存器输出和不同驱动版本的数据布局不能混用。

## 机械与布板约束

- 明确定义芯片坐标系、PCB 坐标系和产品坐标系，并把轴向变换保存在固件配置中。
- 远离扬声器、电机、螺丝、卡扣和 PCB 弯曲高应力区域；安装应力和振动会改变零偏。
- 陀螺仪需要上电稳定、静止零偏估计和温漂处理；六轴 IMU 本身不能提供无漂移绝对航向。

## 验证方法

读取 WHO_AM_I；执行自检；完成六面静态加速度标定、陀螺零偏/温漂、采样时间戳、FIFO 溢出、中断和振动测试；保存量程、ODR、滤波及轴变换配置。
