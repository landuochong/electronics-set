# BME280 温湿度气压传感器

## 定位

同时测量相对湿度、气压和温度的低功耗环境传感器，适合小型气象站、室内环境、海拔趋势和 IoT 设备。

## 型号辨别

- **BME280 有湿度测量，BMP280 没有湿度测量。** 采购、丝印、设备 ID 和驱动初始化必须共同确认，不能只相信商家标题。
- 市面模块可能使用不同稳压、电平转换和 I²C 地址配置；当前条目是芯片级集成参考，不代表某个未知载板已经验证。

## 接口与地址

- 支持 I²C 与 SPI；I²C 地址通常由 SDO 状态选择 `0x76` 或 `0x77`。
- VDD 为 1.71–3.6 V，VDDIO 范围与主电源不同；裸芯片设计需分别核对。
- 上电后读取芯片 ID、校准系数并检查合理性，再启动补偿算法。

## 测量边界

- 温度通道主要用于内部补偿，靠近热源或封闭外壳时不能直接代表室温。
- 气压换算高度依赖当地海平面气压、天气和温度；适合相对高度趋势，不应直接当作绝对海拔真值。
- 湿度开口需要避免液态水、污染和热源，整机响应受外壳通风影响。

## 验证方法

核对芯片 ID；对比标准温湿度计和气压计；验证 forced/normal 模式、过采样、滤波、休眠功耗及断电恢复；保存补偿算法版本和原始 ADC 值用于问题追踪。
