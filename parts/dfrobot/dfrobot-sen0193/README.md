# DFRobot SEN0193 电容式土壤湿度传感器

## 用途

通过模拟电压反映土壤含水状态，适合智能花盆、自动浇水和盆土干燥提醒原型。

## 接口与供电

- 接口：模拟量 ADC
- 供电：3.3–5.5 V
- 输出必须连接到主控可用的 ADC 引脚。

## 设计约束

- 不能把输出值直接当作统一的“湿度百分比”。
- 必须针对实际土壤、探头安装深度和干湿样本标定阈值。
- 长期埋土使用前需要验证防水、腐蚀和漂移。
- 选择 5 V 供电时，必须确认最大模拟输出不会超过 MCU ADC 输入范围。

## 验证建议

记录空气、干土、目标浇水阈值和饱和土壤四个状态的 ADC 原始值，重复插拔后检查阈值稳定性。
