# u-blox MAX-M10S GNSS 模组

## 定位

面向低功耗标准精度定位的多星座 GNSS 模组，可并发接收主要 L1 星座，适合无人机、地面机器人、资产定位和时间同步。

## 能力边界

- GNSS 需要开阔天空视野；室内、树下、城市峡谷、机体遮挡和强多路径环境会明显恶化定位。
- 标准精度 GNSS 不等于 RTK 厘米级定位；精密无人机应根据需求选择双频/RTK 模组并配置基站或改正服务。
- **GNSS 信号无法在水下正常工作。** 潜水机器人只能在水面定位，水下需要 DVL、惯导、声学定位或缆系参考。

## 射频设计

- 天线、地平面、馈线、LNA/SAW 配置和机体安装决定实际性能；不能只按模组参数评估。
- 远离高速数字线、DC/DC、电调和无线发射机，验证整机自干扰与谐波。
- 保存天线类型、线缆损耗、动态平台参数和 GNSS 配置版本。

## 安全与验证

同时检查位置、速度、卫星数、DOP、保护等级/完整性信息以及干扰和欺骗告警。执行冷启动、热启动、遮挡、快速运动、失锁恢复和返航降级测试，不能只判断是否输出经纬度。
