# STM32U575ZI MCU

## 定位

Cortex-M33 低功耗与安全型 MCU，适合电池设备、安全连接设备、较复杂 UI/数据处理和需要 TrustZone/安全启动能力的项目。

## 选型提示

- “低功耗 MCU”不代表使用 Nucleo 开发板即可获得同等低功耗；整板调试器、稳压、LED 和外设都会影响结果。
- 使用安全功能前必须定义密钥生命周期、安全启动、固件升级和生产烧录流程。
- 需要无线连接时仍需外部无线模组，或选择集成无线的其他系列。

## 自研板约束

电源域、去耦、时钟、USB、调试、安全状态和低功耗唤醒引脚需要在原理图阶段逐项审核；封装后缀变化必须重新生成引脚计划。
