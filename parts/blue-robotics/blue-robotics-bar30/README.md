# Blue Robotics Bar30 深度/压力传感器

## 定位

基于 MS5837-30BA 的水下安装模块，用于 ROV/AUV 的压力、深度和温度测量，标称可覆盖约 300 m 水深，并提供适配水密舱的 bulkhead 结构。

## 关键安装边界

- Bar30 本体并非可以整件随意浸水；只有传感面可接触水，线缆背面必须安装在水密舱内，并通过 O 形圈压紧形成密封。
- 产品官方说明适合间歇浸水，并要求每天干燥至少约 2 小时以保持精度；长期部署应选择 BarXT 等相应产品。
- I²C 固定地址 `0x76`，一条总线通常只能直接连接一只 Bar02/Bar30。

## 深度计算

水面执行压力归零；根据淡水/海水密度和当地重力换算深度；温度通道主要用于补偿，不能替代专门的高精度水温探头。

## 安全与验证

深度额定值不能替代整机压力等级。最终水密舱、端盖、穿舱件和线缆必须完成压力循环、保压、漏水和机械检查；软件应对异常跳变、I²C 丢失和超量程进入安全上浮/停止策略。
