# BMP390 气压传感器

## 定位

24 位低噪声绝对气压传感器，适合高度变化、楼层识别、运动设备、无人机和气压趋势测量。官方全精度压力范围为 300–1250 hPa，最高采样率可达 200 Hz。

## 接口与供电

- 支持 I²C 与 SPI；I²C 地址可配置为 `0x76`/`0x77`，条目默认按 `0x77` 规划。
- VDD 为 1.65–3.6 V，VDDIO 可低至 1.2 V；成品模块是否支持 5 V 必须看载板电路。
- FIFO、数据就绪中断和滤波可减少主控唤醒，但配置必须与采样率和动态响应共同设计。

## 机械与气流约束

- 压力开口不能被胶水、清洗剂、防水材料或外壳结构堵塞。
- 风压、风扇、扬声器、密闭壳体和温度梯度会造成明显偏差。
- 焊接应力和 PCB 弯曲可能产生零点漂移；避免放在螺丝、卡扣和板边高应力区域。

## 高度换算边界

气压高度受天气与参考海平面气压影响。楼层/相对高度应用应做基线更新和温度补偿，不能把一次气压读数直接当作绝对高度。

## 验证方法

完成静态零点、温漂、短期噪声、采样率/FIFO、密封壳体响应和动态高度测试；保存原始压力、温度、滤波参数及参考气压。
