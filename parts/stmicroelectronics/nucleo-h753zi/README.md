# NUCLEO-H753ZI

## 定位

基于 STM32H753ZI 的 Nucleo-144 高性能开发板，适合复杂控制、工业以太网、高速采集、图形与需要硬件密码加速的原型。

## 选型提示

- H7 更适合算力、带宽和大存储需求；普通传感器节点通常没有必要承担其成本、功耗和 PCB 复杂度。
- 板载 STLINK-V3E、以太网、USB 和扩展接口属于开发板能力，量产裸 MCU 方案必须重新设计对应电路。
- CAN FD 需要外部收发器；以太网需要 PHY、磁性器件、RJ45 与阻抗/EMC 设计。

## 开发约束

- Cortex-M7 Cache、DMA 与非缓存区配置不当会造成难复现的数据一致性问题。
- 高速外设与外部存储需要时钟树、信号完整性、电源域和 MPU/Cache 联合评审。
- 整板功耗没有内部实测值，不用于低功耗承诺。
