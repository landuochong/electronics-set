# MS5837-30BA 水下压力传感器

## 定位

工厂校准的 24 位绝对压力与温度传感器，量程 0–30 bar，面向潜水电脑、水深测量和水下仪器。官方资料给出的水深分辨率可达到毫米级，但整机深度精度还取决于安装、基准和水体参数。

## 接口与算法

- I²C 固定地址 `0x76`，同一总线多颗传感器需要多路复用器或独立总线。
- 必须读取 PROM 校准系数并校验 CRC，再按数据手册执行一阶/二阶温度补偿。
- 压力换算深度需要扣除水面大气压，并使用实际淡水/海水密度；不能用固定常数覆盖所有海域和温度。

## 防水边界

- 传感元件的凝胶/金属帽可接触水，不代表 PCB、焊盘、线缆和连接器自动防水。
- 需要设计 O 形圈、压力端口、腔体排气和结构强度；避免气泡停留在压力口。
- 凝胶需防止尖锐物、清洗剂、油污和长期不兼容介质损伤。

## 验证方法

完成 PROM CRC、空气零点、水面归零、已知水深、温度循环、升降压滞后和压力舱测试；记录大气压、水密度、温度补偿算法及封装批次。
