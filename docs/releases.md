# 发布与接入

维护以源文件为准；工具不自动提交或推送。公开发布由维护者明确执行。ForgeAI 单独锁定本仓库版本。

发布前：审核迁移报告，运行校验和测试，检查许可证，生成索引，然后人工创建版本 tag。

`tools/export.py` 输出 catalog、knowledge、manifest。manifest 记录源文件 SHA-256 与 Git commit（如果已有提交），相同源数据可生成相同文件。dist 是派生数据，不是维护入口。

下游应用应保存：仓库版本/commit、条目 ID、part.json 内容哈希及当时使用的条目快照。不能只保存型号并在每次打开旧工程时换用新参数。

AI 可用 knowledge.json 的正文做检索，但最终选型需用结构化参数及规则进行约束检查。默认排除 needs_review；若研究模式允许使用待复核资料，必须明确显示风险。

后续可加入静态搜索站点、API、KiCad 映射与驱动包；它们是消费者或扩展，不应成为知识库的必需运行条件。
